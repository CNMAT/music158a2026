ABL Help Files v6
=================

74 tested ABL v5 helpfiles upgraded with the AMXD v27 visual and interaction model, adapted to preserve ABL-specific object contracts.

- Four-inch lower opening position with a one-shot thispatcher window enforcer.
- Shared beige test panel, green preset/effect panel, blue 24 pt Parameter Guide, and red safety caution.
- MUTED remains the default source; drumLoop.aif remains non-looping.
- Named ABL_<effect>_send and ABL_<effect>_out_L/_out_R/_out_MONO audio buses support copy/paste use.
- Preset menu recalls only; STORE/OVERWRITE uses a separate 1–24 number and red bang.
- Choose Preset is the default no-selection menu item.
- External receive ABL_<effect>_preset recalls slots 1–24 and synchronizes the menu/store number.
- The tested ABL v5 state-capture, randomizer, preset-bank, bootstrap, and installed-package help-link engines are retained.
- Every Parameter Guide explains each exposed parameter, its likely unit/type, and the effect of lower versus higher settings. Exact ranges remain native to the installed Ableton DSP package.
