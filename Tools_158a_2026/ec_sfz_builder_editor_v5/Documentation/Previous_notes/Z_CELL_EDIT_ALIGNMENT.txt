EC SFZ Builder v4.2 — cell editor alignment update

INSTALL
Close the builder in Max. Extract the entire updated package, then open
_ec_sfz_builder_editor.maxpat from that extracted folder. Keep every support
file beside the patch. This update needs ec_sfz_table.html and ec_sfz_tables.js
as well as the updated patch, controller, and pane transport.

EDITING
Click a cell and type; double-click or Command/Ctrl+A selects existing text.
Return finishes editing without moving the cell. Tab moves to the next editable
cell. Escape restores the value that was present when editing that cell began.
Scroll vertically for rows and horizontally for columns/long sample fields.
The header row remains visible while scrolling.

Compile tables applies edits as before. A pending cell edit is captured even
if Return has not been pressed. Save, scope changes, Copy/Delete, and other
builder actions also capture current table drafts before continuing.
ID/Group and Opcode/Comment columns remain read-only. Use=1 with Value=0 keeps
an actual zero value. Use=0 still removes the local opcode when compiled.

WHAT CHANGED
The two visible tables now use embedded HTML grids with inputs positioned
inside their own cells. They do not use jit.cellblock's floating inline edit
window. Each cell's editor shares the table's scrolling and scaling, preventing
a separate editing overlay from drifting below the selected row.

The existing jit.cellblock objects are retained as hidden draft storage for
the existing compiler. Their native inline editing is disabled. The previous
forced redraw after every click/edit/scroll has been removed.

Table presentation positions, sizes, column widths, fonts, and configured
colors are retained; colors/font settings are read from the original table
objects. The opcode Comment column adapts to the visible table width.
All other patch objects, original patch cords, mapper/audio/MIDI code, sample
files, authored SFZ instruments, and tutorials are retained.

VALIDATION
12 controller checks and 14 Chromium browser checks passed, covering:
- Cell alignment while editing after horizontal/vertical scrolling.
- Selection/replacement of existing text, Return, Tab, and Escape.
- Output opcode / Value separation, resizing, and 80/125/150% CSS zoom at 2x.
- Zero and empty values, Unicode paths, compile/revert, Copy/Delete, and Undo.
- Capturing active edits before actions; timeout recovery; rejecting stale or
  read-only cell writes; preserving invalid drafts for correction.
Patch connections, nested patchers, and unchanged presentation layout checked.

These checks use a browser and a simulated Max message interface. This runtime
cannot run the Max application, its native jweb bridge, or sfizz~ audio.
Please check an output Value and a sample cell after scrolling in Max, then
Compile tables and confirm the result in the SFZ Program.
