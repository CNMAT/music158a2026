ADSR preset recall repair 1.7 — 2026-10-16

THREE CORRECTIONS
1. The attached help's p preset connected its inlet to the RIGHT inlet of the
   message box. Its saved message began 'set preset 1 ...'. The connection now
   uses the LEFT inlet, and only the leading 'set ' was removed from the saved
   message. All encoded preset chunks and its checksum are unchanged.

2. The controller restored UI values and then sent bang to replay each one.
   A bang to a toggle reverses its value. This disabled saved loop switches
   and also affected other synth toggles. Toggles now receive their explicit
   saved number: int when output is needed, set for silent restoration.

3. Global duration and smoothing appeared after the individual lanes in the
   manifest. Replaying them last overwrote lane-specific values. All four
   global ADSR controls now restore first, followed by individual controls,
   sampled point lists, engine states and finally edited function values.
   Function output refreshes the stored envelope used by the next trigger.
