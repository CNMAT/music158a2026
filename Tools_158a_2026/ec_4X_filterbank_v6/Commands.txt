level <dB> [ms] Output trim for the selected filter: -24 to +12 dB.
band N level <dB> [ms] Output trim for filter N (1-4).
enable N 0 Filter N OFF: fade to silence, without dry signal.
filters 0 All four outputs OFF. Input meters remain active.
restorestate <packet> Restore current settings and the entire preset bank.
band N <command> <arguments> Address a filter explicitly.

Legacy: amp <0..1> maps a positive amplitude to all four output trims.
Values below -24 dB clamp to -24 dB. amp 0 turns all four filters OFF.
Turning a filter back ON retains its fader setting. Use filters 0 for silence.

Type indices: 0 Peak; 1 Lowpass; 2 Bandpass; 3 Ultra; 4 Highpass; 5 Resonant; 6 Notch.
