# Diagnostic provenance

`historical_v21_diagnostics.zip` is the unchanged input package's diagnostic directory, archived under `v21/`. It is historical evidence, not a current v23 result.

The migrated `preset_manifest`, `engine_files`, `reorganization_manifest`, `tutorial_actions`, automixer provenance/examples and `audio_zoom_reference` files are test inputs. They are not proof that native Max was run. Current result files are generated by the executable scripts; `V23_TEST_RESULTS.json` enumerates the 28 current suites. The preservation baseline fingerprints were generated from the actual uploaded ZIP after explicit v21-to-v23 namespace migration.

The legacy compatibility test intentionally creates full v21 payloads; those version strings must remain in that test. The runtime controller retains explicit v21-format migration strings for the same reason. The generic automatic_lines_v5_ed script retains its original version and bytes.
